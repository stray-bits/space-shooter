# space-shooter
A 2D space shooter game in C++, using SFML

## Features
* Spaceship movement
* Enemy spawning
* Shooting mechanics
* Collision detection
* Score tracking
* Sound effects and background music



## Build
```bash
mkdir build
cd build
cmake ..
cmake --build .
```

## Technologies Used
* C++
* SFML 2.x
* CMake
